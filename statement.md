# Project Statement — ARGUS

**Title:** ARGUS — Concurrent Event Investigation & Anomaly Detection Engine

ARGUS is an original Java console application that helps a small security or IT operations team examine event logs. Users can record events, persist them locally, run concurrent anomaly checks, and investigate a selected user's timeline. The project demonstrates object-oriented design, interfaces, file handling, validation/exception handling, multithreading with `Runnable`, and automated tests.

The project intentionally uses transparent, rule-based detection rather than claiming to be a production security information and event management system. Its focus is a complete, understandable academic MVP with a clear path for future extensions such as more rules, JSON input, authentication, and a graphical interface.
